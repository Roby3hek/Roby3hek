# Цели
Поскольку сейчас основной спектр это разработка ПО для ПЛК, опыта в данной сфере у меня гораздо больше чем в остальных. Завел новый профиль и хочу переквалифицироваться и стать Junior Java Developer. В связи с этим прохожу курсы и делаю проекты на Java для своего портфолио. Хочу расти и развиваться в качестве Backend разработчика, и уйти подальше от автоматизации, поскольку автоматизация требует постоянной работы с оборудованием, в том числе на объектах заказчика.  

# Среднее образование
В раннем возрасте, во время обучения в школе, я начал увлекаться программированием. Решал мелкие задачки на Python и Pascal.
После школы поступил в колледж на специальность Информационные системы и программирование.
В колледже по общей программе изучал язык C#. Делал разные десктопные приложения (WPF, WinForms). 
Во время обучения увлекался разработкой мобильных приложений на языке Java (AndroidSDK). Бронзовый призер региональной олимпиады WorldSkills Russia в компетенции «Разработка мобильных приложений» (2022 г.) :3rd_place_medal:.
Для дипломного проекта разрабатывал общую систему для сервисного центра (мобильное приложение и веб сайт с админ панелью). Сайт выполнял функцию визитной карточки и имел возможность загрузить приложение на телефон. С мобильного осуществляется заказ услуги и ее оплата. Данные отправляются в админ панель оператора. С данным проектом можно ознакомиться в репозиториях Roby3hek/byWebApplication и Roby3hek/byMobileApp.

# Работа
После окончания колледжа, устроился на предприятие и поступил в университет.
3 года работаю на данном предприятии. На рабочем месте занимаюсь разработкой ПО для ПЛК, Windows, Linux и SCADA-систем. В основном это ST(МЭК 61131-3), C# и C++. Проекты которые выполнялись на данном предприятии я предоставить не могу. В репозиторирях Roby3hek/universalFrontOdorizator, Roby3hek/testSignalSPK107, Roby3hek/testStendOdorizator можно ознакомиться с тестовыми проектами которые выполнялись вне рабочего времени. В них реализовывается универсальный шаблон для конфигурирования устройства, тестовая панель для устройств подключенных к модулям ввода-вывода ПЛК Овен и полноценный одоризатор газа, который содержит в себе набор алгоритмов и функциональных блоков для работы блока управления.

# Высшее образование 
Также после окончания колледжа, поступил в университет, в 2027 году заканчивается обучение. Специальность Информационные системы и технологии.
В университете расширилл спектр познаний в программировании, выполняя разные проекты для определенных дисциплин. С ними можно ознакомиться в репозиториях Roby3hek/GoRestApi, Roby3hek/AutoMongoDB, Roby3hek/reactViteProject, Roby3hek/CarDiagnostic, Roby3hek/VisionApp. 
                                            
# Коммерческие проекты
Разработал ПО для управления вендинговым аппаратом, генератором сухого тумана. Полностью рабочее программное обьеспечение для аппарата + ведение статистики и управление в телеграмм боте, реализованое на языке C++. Ознакомиться можно в репозитории Roby3hek/TumanIO. Для данного проекта был разработан внешний сайт, для заказа данного оборудования с конструктором примерной стоимости и приемом заявок в админ панели. Ознакомиться можно в репозитории Roby3hek/TumanIOWebApp.
Разработал телеграмм бота для приема заявок для пейнтбол/лазертаг клуба Zona51. Бот находится в репозитории Roby3hek/zona51.
