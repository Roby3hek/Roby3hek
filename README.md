# Среднее бразование
В раннем возрасте, во время обучения в школе, я начал увлекаться программированием. Решал мелкие задачки на Python и Pascal.
После школы поступил в колледж на специальность Информационные системы и программирование.
В колледже по общей программе изучал язык C#. Делал разные десктопные приложения (WPF, WinForms). 
Во время обучения увлекался разработкой мобильных приложений на языке Java (AndroidSDK). Бронзовый призер региональной олимпиады WorldSkills Russia в компетенции «Разработка мобильных приложений» (2022 г.).
Для дипломного проекта разрабатывал общую систему для сервисного центра (мобильное приложение и веб сайт с админ панелью). Сайт выполнял функцию визитной карточки и имел возможность загрузить приложение на телефон. С мобильного осуществляется заказ услуги и ее оплата. Данные отправляются в админ панель оператора. # Работа
После окончания колледжа, устроился на предприятие и поступил в университет.
3 года работаю на данном предприятии. На рабочем месте занимаюсь разработкой ПО для ПЛК, Windows, Linux и SCADA-систем. Проекты которые выполнялись на данном предприятии я предоставить не могу. В репозиторирях Roby3hek/universalFrontOdorizator, Roby3hek/testSignalSPK107, Roby3hek/testStendOdorizator можно ознакомиться с тестовыми проектами которые выполнялись вне рабочего времени.
